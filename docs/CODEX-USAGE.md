Pinned from codex-cli 0.160.0 generated JSON schema and TypeScript on October 7, 2026. Account reads only: account/read with exactly {refreshToken:false}; account/rateLimits/read with {excludeResetCreditDetails:true} (no supportsLunaReserve); account/usage/read with {} (no threadId). Every other method/parameter refused before process dispatch. No credentials/auth.json, tokens, session content, account IDs/emails/identifiers, config or model calls. No daemon lifecycle management by HARNESS.

Transport: fixed ~/.codex/app-server-control/app-server-control.sock, Node net Unix connection with RFC6455 handshake/framing, verified socket/current-user ownership and private permissions, bounded 256KiB stream and eight-second total deadline; cancellation closes only this connection. The installed proxy timed out for newline JSON. Official pinned client source proves Unix routes carry WebSocket frames: [remote.rs rust-v0.160.0](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/app-server-client/src/remote.rs), connect_unix_socket_endpoint; [CLI proxy](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/cli/src/main.rs) forwards raw stdio bytes. This is an equally narrow documented local route; HARNESS cannot select an endpoint or start a daemon. Fixed initialize + initialized connection handshake negotiates no attestation/experimental features and suppresses all schema-pinned notifications except account/rateLimits/updated. These connection control frames are internal, not caller-selectable account methods. Unexpected requests/notifications are discarded without replies, storage or logging. Sparse rate-limit notifications request a fresh bounded snapshot rather than clearing last-good windows. No general RPC endpoint: authenticated GET /api/usage/codex only, no parameters/body; same Host/token/Origin/Fetch Metadata gates and CSP.

RateLimitWindow has usedPercent, windowDurationMins, resetsAt; remainingPercent is derived as 100 minus explicit usedPercent. Prefer rateLimitsByLimitId.codex, otherwise the legacy rateLimits view only when no multi-bucket data exists. Never choose another model bucket silently. PlanType is a pinned enum; all identifiers stripped before HTTP/cache/evidence. Scope: account-wide Codex subscription windows. Missing values stay UNKNOWN; stale last-good values survive failure; timestamps America/Chicago. Successful reads refresh every 10 seconds in both browser and bridge; Claude capture checks also run every 10 seconds without changing the capture’s observation time. Polling coalesces and backs off 30s through 300s on failures; cancellation and disposal stop pending socket reads. No automatic auth repair.

GetAccountTokenUsageResponse has account-wide summary and dailyUsageBuckets {startDate,tokens}. estimatedUsageUsdMicros exists only in ThreadUsage, requiring forbidden threadId; therefore account-wide USD estimate is UNKNOWN. Separate estimated-USD row never treats subscription percentages as money or zero. Unsupported/unauthenticated/missing daemon states retain observed category/code, no raw errors or private payloads exported.
